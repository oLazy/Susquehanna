# Effective Modern C++ — Code Review Notes

This repository contains my personal study notes and code snippets from  
**Scott Meyers’ _Effective Modern C++_ (2014)**.  

The goal is twofold:
1. **Refresh my modern C++ knowledge** before technical interviews.  
2. **Provide runnable examples** that illustrate each item/chapter.  

All examples are written in **C++17** (with occasional C++20 extensions noted).  
Each file is self-contained and demonstrates one or more key guidelines.
